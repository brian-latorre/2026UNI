# Changelog — 2026UNI Modpack

## [1.3.0] — 2026-07-22

### Línea base
- Migración del sistema de distribución: de zip manual (Google Drive + SKLauncher) a instalador automático (Prism Launcher + packwiz)
- 264 mods activos en Minecraft 1.20.1 + Forge 47.4.16
- Incluye configuración completa (`config/`, `options.txt`, `resourcepacks/`, `shaderpacks/`)
- IP del servidor pre-cargada en la instalación
- Actualización automática en cada "Play" via packwiz

### Notas
- Esta es la primera versión publicada con el nuevo sistema
- Los usuarios que tengan la versión anterior (via Drive/SKLauncher) deben reinstalar con el nuevo instalador
