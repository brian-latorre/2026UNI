# 🎮 2026UNI — Manual de Instalación

## Lo que necesitas

- Una PC con Windows 10 o 11 (64 bits)
- Al menos 8 GB de RAM
- Conexión a internet

**NO necesitas instalar Java, ni ningún launcher, ni descargar mods. Todo viene incluido.**

---

## Instalación (una sola vez, ~5 minutos)

### Paso 1: Descargar el instalador
Descarga `2026UNI-Setup.exe` desde el link que te mandó Brian.

### Paso 2: Ejecutar el instalador
1. Haz doble clic en `2026UNI-Setup.exe`
2. Si Windows SmartScreen muestra una advertencia, haz clic en **"Más información"** → **"Ejecutar de todas formas"** (es seguro, solo pasa porque el instalador no tiene firma digital)
3. Sigue el asistente: **Siguiente → Siguiente → Instalar → Finalizar**
4. El instalador se encarga de todo: launcher, Java, mods, configs, IP del servidor

### Paso 3: Primera vez que abres
1. Haz doble clic en el acceso directo **"2026UNI"** que quedó en tu escritorio
2. Prism Launcher te va a pedir que agregues una cuenta:
   - Haz clic en **"Accounts"** (arriba a la derecha)
   - Selecciona **"Manage Accounts"** → **"Add Offline"**
   - Escribe tu nombre de usuario (el que quieras usar en el server)
   - Haz clic en **"OK"**
3. Haz clic en **"Play"** (o doble clic en la instancia "2026UNI")
4. La primera vez va a descargar los mods (~puede tomar unos minutos dependiendo de tu internet)
5. ¡Listo! El servidor ya aparece en la lista de servidores

---

## Jugar (de ahí en adelante)

1. Abre el acceso directo **"2026UNI"** del escritorio
2. Haz clic en **"Play"**
3. Listo — si hay actualizaciones, se descargan solas antes de abrir el juego

**Eso es todo. Nunca más tienes que tocar Java, descargar zips, ni configurar nada.**

---

## Solución de problemas

### "El juego no abre / se queda en pantalla negra"
- Intenta cerrar y volver a abrir
- Si persiste, contacta a Brian

### "Me sale un error de Java"
- El instalador incluye su propio Java, no deberías ver este error
- Si pasa, contacta a Brian

### "Quiero cambiar la RAM asignada"
1. Abre Prism Launcher
2. Clic derecho en la instancia "2026UNI" → **"Edit"** → **"Settings"** → **"Java"**
3. Cambia "Maximum memory allocation" al valor que quieras (recomendado: 5120 MB)

### "¿Puedo agregar mis propios mods?"
- **No recomendado** — puede causar incompatibilidades con el servidor
- Si agregas mods de cliente (como shaders extra o minimapas), deberían funcionar, pero cualquier problema es bajo tu responsabilidad

### "¿Cómo desinstalo?"
- Menú Inicio → busca "2026UNI" → "Desinstalar 2026UNI"
- O desde Configuración de Windows → Aplicaciones → 2026UNI Modpack → Desinstalar

## ¿Qué se actualiza automáticamente?

| Se actualiza solo | NO se toca (tuyo) |
|---|---|
| Mods | Waypoints del minimapa |
| Configuración de mods | Screenshots |
| Paquetes de texturas | Esquemáticos |
| Shaders | Grabaciones de voz |
| Configuración de video/controles | Mundos locales (singleplayer) |
